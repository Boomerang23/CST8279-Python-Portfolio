# Mid Term Python Project – Drawing Shapes

## Project Overview

This project was completed for CST8279 – Introduction to Computer Programming Using Python.

The objective was to create a Python function capable of drawing a square in the terminal based on a size provided as an argument.

## What I Implemented

- A 'draw_square(size)' function
- Input validation for invalid sizes
- A 'draw_rectangle(width, height)' function
- A 'TerminalScribe' class containing a 'draw_square()' method
- 'for' loops to generate shapes using asterisks

## Skills Demonstrated

- Python functions and arguments
- Loops
- Conditional statements
- Input validation
- Basic object-oriented programming
- Code organization and testing
