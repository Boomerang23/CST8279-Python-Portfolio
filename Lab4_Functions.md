# Lab 4 – Defining and Calling a Python Function

## Project Overview

This project was completed for CST8279 – Introduction to Computer Programming Using Python.

The objective was to demonstrate how to define and call a Python function.

## What I Implemented

The program defines a function that receives a name as input and prints an introduction line using that name.

The function is then called to execute the code and display the result.

## Skills Demonstrated

- Defining Python functions
- Calling functions
- Function parameters
- Passing arguments
- Working with strings
- Printing program output
- Using code comments
