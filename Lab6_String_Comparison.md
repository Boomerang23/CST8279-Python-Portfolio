# Lab 6 – String Comparison in Python

## Project Overview

This project was completed for CST8279 – Introduction to Computer Programming Using Python.

The objective was to create a Python program that compares two strings and determines whether they are equal or different.

## What I Implemented

The program demonstrates string comparison using Python's equality and inequality operators:

- '==' to check whether two strings are equal
- '!=' to check whether two strings are different

The program uses conditional logic to display the result of the comparison.

## Skills Demonstrated

- Python strings
- Comparison operators
- '==' and '!='
- Conditional statements
- Basic program logic
- Testing program output
