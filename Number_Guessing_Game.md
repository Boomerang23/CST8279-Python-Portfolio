# Number Guessing Game

## Project Overview

This Python game was created for my CST8279 technical portfolio.

The computer randomly selects a number between 1 and 100. The player repeatedly enters guesses until the correct number is found.

After each guess, the program tells the player whether the guess is too high or too low.

## Game Features

- Random number generation
- User input
- Input validation
- High and low hints
- Attempt counter
- Error handling for invalid input

## Skills Demonstrated

- Python functions
- 'while' loops
- Conditional statements
- Variables
- User input

- Random numbers
- Basic game logic
