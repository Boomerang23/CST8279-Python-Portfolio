# Technical Portfolio – Reflective Report

Creating this technical portfolio gave me the opportunity to look back at the work I completed throughout CST8279 – Introduction to Computer Programming Using Python. At the beginning of the course, I was mainly focused on understanding basic Python syntax and learning how to write programs that worked correctly. Building this portfolio helped me see how much my programming skills developed during the course.

One of the most useful parts of the process was selecting my five projects. I chose projects that demonstrate different Python concepts instead of choosing similar exercises. For example, my Mid Term Python Project demonstrates functions, loops, validation, and basic object-oriented programming. My debugging project demonstrates problem-solving and testing, while my other projects show my understanding of tuples, string comparison, and defining and calling functions.

Creating the Number Guessing Game was another important part of the portfolio. It allowed me to combine several concepts in one program, including random numbers, loops, conditional statements, user input, functions, and exception handling. This project helped me understand how individual programming concepts can work together to create an interactive application.

I also experienced some challenges while building the portfolio. Organizing the projects in a way that would be understandable to someone who did not take the course required more than simply uploading code. I created descriptions for each project and used GitHub to organize the source files, reports, and explanations. I then connected these projects to Clippings.me using web links. This helped me understand that a technical portfolio should not only contain working code but should also clearly communicate what the code does and what skills were used.

Selecting three Python articles also helped me think about the broader applications of the language. Python can be used in many areas of technology, and the articles gave additional context to the programming concepts studied during the course.

Overall, creating this portfolio helped me recognize my progress as a beginner Python programmer. I improved my ability to write, test, debug, and explain Python programs. I also learned how to present technical work in a more organized and professional way. I can continue adding projects to this portfolio as my programming skills develop.
