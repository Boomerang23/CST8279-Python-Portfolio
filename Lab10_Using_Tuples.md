# Lab 10 – Using Tuples in Python

## Project Overview

This project was completed for CST8279 – Introduction to Computer Programming Using Python.

The objective was to demonstrate how tuples work in Python, including accessing elements, using negative indexing, and understanding tuple immutability.

## What I Implemented

### Accessing Tuple Elements

I created a tuple containing programming languages and accessed a specific element using its index.

Example:

'languages = ("Python", "Java", "C++", "JavaScript")'

### Negative Indexing

I demonstrated how negative indexes can be used to access elements starting from the end of a tuple.

For example, index '-1' accesses the last element.

### Tuple Immutability

I demonstrated that individual tuple elements cannot be deleted or modified.

The program uses 'try' and 'except' blocks to handle the errors produced when attempting to delete a tuple element and when accessing a tuple after deleting the entire variable.

## Skills Demonstrated

- Python tuples
- Indexing
- Negative indexing
- Immutable data structures
- Exception handling
- 'try' and 'except'
- Data organization
